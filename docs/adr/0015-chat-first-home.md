# 0015 首頁就是一句問候和一個輸入框，選單變成對話紀錄；配色改中性（修正 ADR 0013 的第 1 點與第 3 點）

日期：2026-11-12　狀態：已決定（使用者 2026-11-12 要求「用 UI 設計師的角度，讓整體使用流程更順利上手，介面優化更接近極簡對話風格」；設計由協調者決定（依「介面改版由我主導」）；v0.23.0「極簡對話 1」做完後定稿。細節依 ADR 0001、0003、0013、0014、GLOSSARY 與 `docs/SECURITY-MODEL.md` 的「Chat-first home (v0.23)」）

## 背景

v0.21.0 把選單縮成四項、首頁做成三塊加一個輸入框；v0.22.0 讓首頁先畫框、等你按的卡片算進數字。第一次用的人現在看到的首頁，從上到下是：一個大標題「首頁」加一句說明、等你決定、我的員工（加一句「點頭像就能聊」與「新增員工」大按鈕）、今天、最後才是輸入框。
想跟 CEO 說話的人，要先越過四塊東西才找到框；左欄的四項選單又占了最醒目的位置，而每天會做的事其實只有一件：說一句話。配色是米色底、綠色強調，加上卡片框、陰影與底色，整個畫面「有很多東西」。
使用者希望更接近極簡對話介面（一句問候、一個框、其餘退後）。

## 決定

1. **選單改成：品牌、「新對話」、「最近」，下面小一級的員工、工作、設定（再下面是進階模式的那幾項）**（**修正 ADR 0013 第 1 點「選單四項：首頁、員工、工作、設定」**）。
   - 「新對話」就是原本的首頁項目：`href="#/"`、`data-nav="home"`、亮燈規則與 `NAV_PARENT` 都不變，只有字改了；已經在首頁時按了把游標放回輸入框。它本身不開任何對話、不發請求。
   - 「最近」列出聊過的員工（最多 8 個，最近的在上，每列是名字，點了開那個員工的聊天）；有卡片等你決定的那列前面有一個小點（`aria-label`「有事等你決定」）。資料**只**來自首頁已經讀到的 `GET /api/chats` 結果與「等你決定」手上的資料，這一段**不另外讀、不設計時器**（因為 `GET /api/chats` 每次會讓主控台去跑三個 AI 工具的 `--version`）；沒有資料或沒人聊過時整段不顯示，不寫「沒有對話」（不知道）。只放伺服器給的事實，不編對話標題、不顯示訊息內容。
   - 員工、工作、設定三項的 `href`、`data-nav` 不變。圖示改成簡單字元（設定的 ⚙ 改成 ◇，避免被畫成表情符號）。桌面左欄寬 232 改約 220。
   - 手機（720px 以下）：頂端一條（品牌加「選單」鈕），左欄變成從左邊滑出的抽屜；點連結、按 Esc、點抽屜外面都會關；選單鈕的 `aria-expanded`、`aria-controls` 照實；`prefers-reduced-motion` 時不做滑動。原本的「進階」鈕併進抽屜（進階項目在抽屜裡，照 `data-advanced` 顯示），`#nav-toggle` 這個 id 留給新的選單鈕。
2. **首頁以輸入框為主**（**修正 ADR 0013 第 3 點「首頁三塊加一個輸入框」**）。有 CEO、可以聊的人，從上到下：
   - 等你決定：有事（N ≥ 1）時是一顆藥丸「有 N 件事等你決定」，按了在原地展開原本的清單（`homeWaiting`，內容、按鈕、請求都沿用）；N = 0 而且確定讀完時整塊不佔畫面；資料還沒回來寫「載入中」、不當成 0（ADR 0014 第 9 點照舊），讀不到照舊說讀不到。
   - 一行問候「今天想做什麼？」（原本的 `h1` 與說明拿掉，留一個視覺隱藏的 `h1` 給螢幕閱讀器）。
   - 輸入框（原本的 `homeAsk`，邏輯與請求不變）：圓角大框，送出鈕在右下角，隨內容長高（最多約 8 行）。**Cmd/Ctrl + Enter 送出，Enter 單按不送**（避免誤送與花費）。頁面畫好後游標放進框，只在首頁、只在沒有其他元素被聚焦時、而且不在觸控裝置上（鍵盤會蓋住畫面）。`HOME_CEO_ASK` 說明留在框下方小字。
   - 範例句三顆（只在還沒聊過時）：「幫我整理今天的待辦」「幫我寫一篇貼文」「每天早上給我一份摘要」。按了**只把字放進輸入框並聚焦**，不送、不發任何請求；框裡已有字時取代它（先不做確認）。
   - 我的員工縮成小頭像加名字，最後一顆是「＋」（`aria-label`「新增員工」）；今天縮成一行灰字（加原本的連結）；「最近聊過誰」移到左欄。
   - 沒有員工的人照舊看三步（準備 AI 工具、建立 CEO、說第一句話）；還不能聊時照舊顯示原因與「先把聊天準備好」；進階模式的舊區塊照舊接在最下面。內容欄置中、最寬 720px；清單都空時上方留約 22vh。
3. **配色改中性、少框**：淺色與深色的基本色改成不帶綠、不帶米色的灰（淺：白底、`#f5f5f4` 次底、`#17191a` 字；深：`#111213` 底、`#17191a` 面、`#ecedeb` 字），左欄底色比主畫面深或淺一階（新的 `--side-bg`）；綠色 `--accent` 只用在主要動作（`.btn.primary`）與目前所在選單項的文字，不當大面積底色。全站 `.btn` 改圓角膠囊，`.card` 去掉陰影、留框線，首頁區塊沒有卡片框與底色。**狀態色（ok、warn、bad、info）、辦公室頁、卡牌與陣營框的顏色不動。** 文字對比不低於 v0.22.1，而且都達到 4.5:1（淺色的 `--ink-3` 由計畫的 `#6b7173` 微調成 `#686e70`，才在淺灰底上也有 4.5:1）。
4. **只改畫面。** 不改 `vbear/` 的任何伺服器、啟動邊界、聊天、花費程式（版本號那一行除外）；不新增 API 路徑、請求種類、設定鍵、資料檔、事件種類或瀏覽器 `localStorage` 鍵；守門規則 15b 照舊通過；每天上限、每回合上限、定時工作上限、權限卡片與警語一個都沒動。

## 考慮過的其他選項

- **把「最近」做成伺服器端的對話標題清單**：要新的 API 與標題欄位；也會讓畫面顯示訊息內容。這版只用已讀到的事實（名字、有沒有卡片在等），標題留給之後。
- **左欄自己每隔一陣子讀 `GET /api/chats` 讓清單即時**：每次讀都會執行真的 AI 工具的 `--version`；用既有的 30 秒讀法就夠，不另起計時器。
- **Enter 單按送出（像一般聊天軟體）**：誤送會直接花錢；維持 Cmd/Ctrl + Enter（ADR 0013、15c）。
- **範例句按了就送出**：第一句話要用的人自己決定與按送出；範例只填字。
- **這版就做第二、三張畫面（聊天頁與設定頁改版）**：只改首頁與左欄，其餘頁只吃到變數與共用樣式（按鈕、卡片）的變化，不逐頁重排；聊天頁等後續版本。
- **選單保留四項、只把輸入框拉到最上面**：左欄仍占最醒目的位置，也看不到最近聊過誰。
- **所有顏色重配（包含狀態色與辦公室頁）**：狀態色與卡牌是意思的一部分、辦公室有自己的設計，不在這版動。

## 後果

- 第一次打開的人看到一句問候和一個框，第一句話少越過四塊東西；回來用的人從「最近」一點就回到上次的對話。
- 選單第一項叫「新對話」，頁面本身仍叫「首頁」（只剩給螢幕閱讀器的標題與文件裡的名字）；GLOSSARY 新增「新對話」「最近」，`WORDS` 同步。
- 「最近」在首頁讀完聊天清單之前是空的，在別的頁停留時最多慢 30 秒更新（沿用「等你決定」的讀法）。這是已知限制。
- 範例句取代輸入框裡已有的字，沒有確認；已知限制。
- 守門規則 17（17a–17c）把這些寫成測試，見下。
- 回到 v0.22.1：沒有資料要轉換，沒有新的設定鍵或瀏覽器鍵。

## 守門規則 17（寫成測試，規則 1–16 一條沒放寬；15b 不改、照舊通過）

- **17a 範例句只填字、不送**（`tests/test_autonomy_guard.py`，加 `tests/frontend/p50_home.cjs`）：處理範例句的函式不發請求、不呼叫送出，只寫輸入框的值與 focus；按下去 0 個請求。
- **17b 左欄「最近」不另外讀、不設計時器**（同一個檔，加 `tests/frontend/p50_nav.cjs`）：畫「最近」的程式不呼叫 `api.get("/api/chats")`、不用 `setInterval` 或 `setTimeout`；畫面上它只用已讀到的資料。
- **17c 首頁輸入框只有 Cmd/Ctrl + Enter 送出**（同一個檔，加 `tests/frontend/p50_home.cjs`）：keydown 只在 Enter 加 meta 或 ctrl（而且不是輸入法組字中）時送出；沒有 keypress、keyup 或表單 submit 的送出路徑。

另有 `tests/frontend/p50_theme.cjs`（顏色、對比、膠囊按鈕、卡片無陰影、狀態色不動）與 `tests/test_p50_docs.py`（文件與守門檔都在、帶規則號碼）不屬於守門規則，但一起跑。

## 這版沒有改的邊界

這版沒有碰啟動邊界：`vbear/` 只有 `__init__.py` 的版本號一行不同；沒有新的 API、設定鍵、資料檔、事件種類或瀏覽器 `localStorage` 鍵。`docs/SECURITY-MODEL.md` 只加一小段「Chat-first home (v0.23)」寫明這一點，不改任何邊界段落。

## 真機驗證

這版的外觀（兩種主題、桌面與 400px 寬、手機抽屜）要由協調者用暫存主控台（埠 7803、暫存 HOME）截圖確認，並記下頁面讀 `GET /api/chats` 的次數；撰寫者沒有開瀏覽器，顏色與對比是用色碼算的。結果由發版的人記在 CHANGELOG 的「On a real Mac」。
