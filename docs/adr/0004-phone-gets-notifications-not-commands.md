# 0004 手機只收通知，不能下指令

日期：2026-11-05　狀態：已決定（使用者在 grill-with-docs Q8 拍板）

## 背景

Grok Bot 一類的服務可以從手機或通訊軟體叫 AI 做事。VBear 只在用的人自己的 Mac 上執行，只接受本機連線。
讓手機能下指令，等於在用的人的電腦上開一扇從外面進來的門。

## 決定

放在路線圖最後面，只做通知：員工做完事、碰到上限、需要按允許時，傳 LINE 或 Telegram 之類的通知。
任何指令與允許都要回到 Mac 上操作。是否升級成手機也能下指令，之後另外討論。

## 考慮過的其他選項

- 不做：出門在外不知道進度，有工作等人按允許時會一直卡著。
- 手機也能下指令、按允許：拿到手機或帳號的人就能指揮電腦裡的員工，風險明顯變大。

## 後果

- 通知內容只能是進度與提醒，不能帶有可以直接執行的連結或按鈕。
- 通知會把一部分資訊送到外部服務，內容要避免檔案內容、路徑與金鑰。
