# 0002 預設安全模式，完整模式要先看懂白話警告

日期：2026-11-05　狀態：已決定（使用者在 grill-with-docs Q2 拍板）

## 背景

目標使用者看不懂終端機（見 0001），也就難以判斷員工要跑的指令是否危險。
目前只有 Claude Code 有安全模式；Codex、AGY，以及要接上的 Grok、MCODE 都只能用完整模式。

## 決定

角色卡出發預設是安全模式。選完整模式時，VBear 用一般人的話說明「這個員工可以動你電腦上的任何檔案」，
用的人勾選「我了解」才會出發。只能用完整模式的 AI 工具，在角色卡上清楚標示。

## 考慮過的其他選項

- 兩種模式並列由人自己選：對看不懂風險的人等於沒有預設。
- 完全不開放完整模式：在各工具有自己的安全模式之前，Codex、Grok、AGY、MCODE 對用的人都不能用。

## 後果

- 開始設定頁就緒的工具，不代表能用安全模式；畫面要分開說清楚。
- 之後替各工具補安全模式時，這個警告才會在該工具上消失。
