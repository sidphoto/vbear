# 0001 目標使用者是連終端機都沒打開過的人

日期：2026-11-05　狀態：已決定（使用者在 grill-with-docs Q1、Q1-1 拍板）

## 背景

VBear 到 v0.11.0 為止，是給會用終端機的人用的：要自己裝好並登入 Claude Code，看得懂 README 裡的指令，
未簽章的 App 要自己到「隱私權與安全性」放行。往 Open_Bot / Grok Bot 的方向發展時，要先決定是為誰做。

## 決定

VBear 公開發行，目標使用者是使用者的朋友這一類人：**從來沒用過終端機的人也要能簡單使用**。
這是朝 Grok Bot 看齊的原因。評估之後每個功能時，以「不碰終端機的人能不能自己完成」為驗收標準之一。

## 考慮過的其他選項

- 只給自己用：可以做得最快，但使用者明確要分享給朋友。
- 以會用終端機的工程師為對象：現在的 README 與 Homebrew 就大致夠用，但不是使用者要的。

## 後果

- 安裝、登入 AI 工具、版本驗證、出錯時的說明，都要能在 VBear 的畫面裡完成，不能要求使用者打指令。
- 每一句畫面上的說明都要用一般人看得懂的話。
- 安全標準不因此放鬆：使用者看不懂風險，VBear 的預設就要更保守。
- 未簽章 App 的「強制打開」、Claude Code 的安裝與登入，會變成必須處理的門檻（另行決定）。

## 補充：AI 工具從哪裡來（Q1-2）

選 A：用的人自己的 Claude Code（及其他 CLI）登入，花自己的方案額度。不做 API 金鑰（B），也不由 VBear 提供 AI（C）。
登入在 VBear 程式裡的終端機進行：開始用 VBear 後，在 VBear 內建的終端機登入各種 CLI，不必另外打開 Mac 的「終端機」App。
VBear 不讀取、不記錄、不顯示登入過程中的代碼或金鑰。

## 補充：開始設定頁（Q1-3）

選 A：第一次打開 VBear 時出現「開始設定」頁，列出各 AI 工具的狀態（還沒安裝／還沒登入／就緒）。
按「安裝」或「登入」時，VBear 開啟內建終端機並代為送出指令，旁邊用一般人的話說明接下來會發生什麼；完成後自動變成就緒。
不採用「只開空白終端機加文字教學」。

## 補充：開始設定列哪些 AI 工具（Q1-4）

選 B：Claude Code、Codex、AGY 三個並列，用的人自己挑要準備哪幾個；不把 Claude Code 定為必要。

## 補充：只有 Codex 或 AGY 的人（Q1-5）

選 C：開始設定頁與各功能頁先標示「這個功能目前需要 Claude Code」並說明如何取得；下一個功能就做 Codex 聊天，
幕僚長派工往後延一格。原因：用的人不論哪種 AI 方案都要能上手，聊天是最基本的功能。

## 補充：先做開始設定頁，AI 工具擴大為四加一（Q1-6）

選 A：先做開始設定頁（v0.12.0），再做 Codex 聊天，之後回到原路線圖。
同時，開始設定頁要串接四個 AI 工具：Claude Code、Codex、AGY、Grok（xAI 的 Grok Build CLI，本機 `grok` 0.2.101）。
另外使用者私人還需要 MCODE（MiniMax Code，本機 `mcode` 0.5.2）。

## 補充：MCODE 是隱藏的私人選項（Q1-7）

選 A：MCODE 預設不顯示，要在設定裡自己打開「顯示 MCODE」才出現；公開的開始設定頁只列四個 AI 工具。
不另外維護私人版程式，也不把 MCODE 完全排除在公開程式之外。

## 補充：v0.12.0 串接到哪裡（Q1-8）

選 A：v0.12.0 讓四個 AI 工具（加隱藏的 MCODE）都能在開始設定頁安裝、登入、顯示就緒，
Grok 與 MCODE 也能放上角色卡、在終端機（完整模式）工作，與現在的 Codex、AGY 同級。
聊天之後逐一補上：Codex → Grok → AGY → MCODE。不一次做齊所有工具的聊天與開會。

## 補充：每天花費上限由用的人第一次自己選（Q4）

選 C：開始設定頁問用的人每天最多花 US$1、US$3 或 US$10，預設選 US$3；之後可以在設定裡改。
Q4-1：兩種上限都支援暫停、倒數與接續。VBear 自己的每天上限在隔天 0 點恢復；AI 工具方案的用量上限
（例如 Claude 的 5 小時用量）依該工具說的恢復時間倒數。自動接續是 0003 的第 5 個勾選項，預設不勾。

## 補充：先不申請 Apple 開發者簽章（Q5）

選 B：先不申請（每年 US$99）。在開始設定頁之前放一頁附截圖的「第一次打開 VBear」教學，
帶用的人到「系統設定 → 隱私權與安全性」按「強制打開」。等真的有朋友卡住再決定是否申請。

## 補充：沒有登入狀態指令的 AI 工具（Q10）

選 A：Claude Code、Codex 用它們自己的狀態指令自動查。AGY、Grok、MCODE 沒有這種指令，裝好後由用的人按「我登入好了」標成就緒；
另有「試一下」按鈕送一句很短的話確認真的會回應，按之前先說明大約花不到 US$0.01。
不偷看各工具的登入資料夾，也不每次打開都自動試。
