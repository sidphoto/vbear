# 0013 一般人看到的 VBear：四項選單、一套「公司」說法、工程頁收進進階模式、花費收起來但上限照樣把關

日期：2026-11-10　狀態：已決定（使用者把介面改版全權交給協調者，並補充「價錢在現在的訂閱下不是重點」；v0.21.0「好上手 1」做完後定稿。細節依 ADR 0001–0012、GLOSSARY 與 `docs/SECURITY-MODEL.md` 的「Plain navigation (v0.21)」）

## 背景

2026-11-09 的介面健檢（截圖 71 張、5 個任務）發現：選單 19 項，混用三套說法（遊戲：冒險者大廳、角色卡、出發、陣營、種族；公司：CEO、員工、派工；工程：終端機、終端工作台、流程、專案、技能庫），
「技能」與「技能庫」、「終端機」與「終端工作台」同名不同物；首頁沒有跟員工聊天的入口，新手第一局帶去 git 任務卡的工程路線；「建立 CEO，開始聊」在 AI 工具還不能聊時退回聊天清單加約 600 字說明；
聊天頁前面五行說明加三個大框，手機要捲約 1,700px 才到輸入框，「刪除這個聊天」緊貼「送出」；設定頁沒有每天花費上限（開始設定頁卻說可以在設定改）；錯誤訊息是工程字（`FileNotFoundError`、`Agent CLI`、`planner`、`manual_review`、孤兒翻譯）；
權限卡片寫 Bash、Edit、「原本的字串」；三處畫面互相矛盾；定時工作新增預設只有週一到週五、而且是關著的。
ADR 0001 要求不開終端機的人也能自己完成每件事、每一句說明都看得懂。使用者覺得 VBear「很難順暢使用」，希望像 iPhone 拿起來就會用；之後補充：在現在的訂閱方案下，價錢不是重點。

## 決定

1. **選單四項：首頁、員工、工作、設定。** 其他頁從這四頁點進去。所有舊路由照舊能開（書籤、文件、測試、程式內的連結都不壞），只是不在選單。
   **v0.23.0 修正（ADR 0015）：** 選單改成「新對話」（原本的首頁項目）、「最近」，加下面小一級的員工、工作、設定；`href`、`data-nav` 不變。
2. **工程頁收進「進階模式」**（沿用設定裡既有的 `advanced_mode`，預設關）：打開後選單多出指令視窗、工作台、流程、專案資料夾、AI 工具的外掛清單、員工詳細資料，並顯示路徑與診斷。
   **進階模式不是權限**：伺服器只存它，不拿它決定任何行為；員工要跑指令、改檔案照樣每次問（守門規則 15a）。進階頁在一般模式照樣能用網址打開，不擋。
3. **首頁三塊加一個輸入框**（**v0.23.0 修正（ADR 0015）：** 首頁改成一句問候和輸入框為主，等你決定縮成一顆藥丸，最近聊過誰移到左欄；只改畫面）：等你決定（不分一般或進階模式，凡是要你決定的都列）、我的員工（點頭像就聊）、今天（今天要做的定時工作、最近聊過誰；不放金額）、「想做什麼？跟 CEO 說」（按送出就送給 CEO，和聊天頁的送出是同一個請求）。
   還沒有員工時只顯示三步：準備 AI 工具 → 建立 CEO → 說第一句話。
4. **只用一套「公司」說法**：員工、新增員工、開始工作、用哪個 AI、外觀、每件事先問我、完全交給他（有風險）、保護範圍、專案、常用做法、分配工作、定時工作、花費上限、對話紀錄……（全表見 v0.21 計畫與 GLOSSARY）。
   遊戲說法只留在辦公室頁。**一般模式看得到的每一頁全換；進階頁這版只換選單名稱與頁面標題**，內文之後視需要再換。程式名、API、資料欄位、事件種類不改。
5. **花費收起來，上限照樣把關**：選單沒有「花費」、這版沒有花費頁、新的一般首頁區塊沒有金額（進階模式下原樣沿用的舊首頁區塊照舊，其中的卡片可以有金額）；每天花費上限與今天的用量放在設定裡預設收起的「用量與上限」，可以選 US$1／3／10 或自己填（0.01–50）；
   開始設定頁的每天上限也改成預設收起（預設 US$3，可以不用動）——**修正 ADR 0001 Q4「開始設定頁問用的人」**：仍然問得到、改得到，只是不擋在新手面前。
   聊天每回合的金額、「估計、不是帳單、用的是你的方案」的說明收進「詳細資訊」；做決定的確認框裡的「最多花多少」照舊。**伺服器的每回合上限、每天上限、定時工作上限、紅燈擋下一條都不改**；被擋下時畫面白話說明發生什麼、明天 0 點重算、可以到設定調高（有按鈕）。
   AI 仍然不能自己調高上限（ADR 0003）。
6. **聊天頁只剩對話**：一行「職位・AI 工具・每件事先問你・對話會送到哪一家公司」加「詳細資訊」；不常用的（請幕僚長安排、整理要記住的事、整理成常用做法、刪除這個對話）收進「⋯」，每一項打開的仍是原本有花費與資料流向說明的確認框；
   每則訊息的按鈕滑過或聚焦才出現（鍵盤可用）；輸入框固定在底部。
7. **「建立 CEO，開始聊」直接進對話**；AI 工具還不能聊時，停在一個只說一行原因、只有一個動作的準備頁（例如「先做一次安全檢查」，按了仍先說明花費並確認），通過後自動開對話、開場白放在輸入框，**按送出才送**。
8. **錯誤白話在畫面做**：伺服器與啟動邊界的句子不改，畫面認得的原句換成白話加下一步，原句整句收進「技術細節」；不認得的照原樣顯示，不猜原因。權限卡片不寫英文工具名（收進技術細節），警語一字不刪。
9. **定時工作新增預設每天、開著**：「自己動手」第 3 項關著時，開著只代表到時間提醒你；第 3 項開著時，存成開著前先確認（和既有的「開啟」按鈕同一句）。團隊範本建的定時工作照舊關著。

## 考慮過的其他選項

- **保留遊戲說法、只加說明**：健檢顯示問題在三套說法混用，加說明只會更長。
- **做一個給新手的獨立 App 或獨立網址**：要維護兩份畫面，安全說明也要寫兩份。
- **刪掉工程頁**：會用的人（包括使用者自己）還需要；而且刪頁要動到伺服器與測試。
- **這版就把進階頁內文全換**：「任務卡」168 處、「出發」97 處大多在工程頁，風險高、對新手沒有好處。
- **花費做成選單一項（原計畫）**：使用者補充價錢不是重點，選單應該留給每天會用的事；完整的花費明細也需要新的彙總 API。
- **把花費上限拿掉或預設不限**：上限是安全機制（ADR 0001 Q4、0003），不放寬。
- **錯誤訊息改在伺服器**：`cli_versions.py` 在啟動邊界內，P19 已有在畫面翻譯、保留原句的做法。

## 後果

- 新手第一次打開只要走三步就能和 CEO 說話；常用的事都在四個選單裡。
- 舊說法進 GLOSSARY 的「避免」欄；之後新的畫面文字照新用語表寫。進階頁的內文暫時仍有舊詞（GLOSSARY 寫明）。
- 進階模式、等你決定、用量與上限是新詞；守門規則 15（15a–15e）把「這版只改畫面」寫成測試：進階模式只管顯示、不加 API 不改欄位與事件、首頁不會自己送、花費上限與定時工作只由用的人按、聊天頁減重不拿掉確認與警語且被上限擋下時有白話與去處。
- 回到 v0.20.0：沒有資料要轉換；自己填的上限與預設開著的定時工作 v0.20.0 都讀得懂；新頁的書籤會顯示「找不到這個頁面」。
- 之後（v0.22.0）：等你決定包含所有聊天卡片、分頁標題數字、可選的 Mac 通知、聊天驗證放背景；花費明細若要做，放在「用量與上限」裡，不回選單。

## 守門規則 15（寫成測試，規則 1–14 一條沒放寬）

- **15a 進階模式只管顯示**（`tests/test_autonomy_guard.py`）：`vbear/` 裡只有 `config.py`（預設值）與 `server.py`（可寫的鍵、轉成布林的那一行）出現 `advanced_mode`；切換它之後，自己動手的設定、花費上限、每回合上限、每位員工的啟動方式都不變；`web/app.js` 只讀它、並在設定頁的開關送出時寫它。
- **15b 不加 API、不改欄位與事件**（同一個檔）：`web/app.js` 用到的 `/api/` 路徑是 v0.20.0 的子集合，`server.py` 的路由和 v0.20.0 相同，聊天紀錄的事件種類與欄位和 v0.20.0 相同。
- **15c 首頁不會自己送**（`tests/frontend/p47_home.cjs`）：畫面載入與打字只發 GET；只有按「送出」才送一則訊息。
- **15d 花費上限與定時工作只由用的人按**（`tests/frontend/p47_settings.cjs`）：設定頁載入不送任何 POST；上限只在按「儲存」時送；「自己動手」第 3 項開著時，定時工作存成開著前先確認。
- **15e 聊天頁減重不拿掉確認與警語**（`tests/frontend/p47_chat.cjs`）：「⋯」裡的每一項仍先確認或先預覽；權限卡片的按鈕與警語一個不少；被上限擋下時白話說明、有「到設定調高」、輸入的字還在。

## 這版沒有改的邊界

這版沒有碰啟動邊界：Python 只改 `vbear/autonomy.py` 與 `vbear/first_ceo.py` 的中文說明字串（`NEVER` 三句意思不變），其餘一行沒動；沒有新的 API、設定鍵、資料檔、事件種類或瀏覽器 localStorage 鍵（聊天清單說明不再記「我知道了」，所以少用一個）。`docs/SECURITY-MODEL.md` 只加一小段「Plain navigation (v0.21)」寫明這一點，不改任何邊界段落。

## 真機驗證

發版前用 `tools/qa_p47.py` 在暫存的狀態資料夾上，v0.20.0 與 v0.21.0 各跑一次同樣的五個任務（第一次用到跟 CEO 說第一句話、把每天上限改成 US$5、新增每天早上 8 點的定時工作、看懂並拒絕一張「修改檔案」卡片、被上限擋下時知道怎麼辦），比較步數、卡住次數、要先讀的字數與手機上輸入框離頁頂多遠；Claude 部分用 Haiku、硬上限 US$0.30。結果由發版的人記在 CHANGELOG 的「On a real Mac」。這個腳本不屬於產品，不在測試裡啟動瀏覽器。
